# 🌟 MAXSAV4 Pro-Maker Hub (Интерактивная Визитка & Портфолио)

> **Статус:** Awwwards / High-End Engineering  
> **Хостинг:** GitHub Pages + Локальный сервер + Удаленный Linux сервер (`192.168.31.195`)  
> **Технологии:** WebXR, `<model-viewer>`, PBR 3D, Canvas Liquid-Goo Simulation, Web Audio API, Responsive 50/50 Split.

---

## 🎨 Возможности и архитектура

1. **⚡ Интерактивный 3D-подиум (Live 3D Stage):**
   - Рендеринг реальных 3D-моделей в формате `.glb` (`terea.glb`, `case.glb`, `pm.glb`, `knife.glb`, `buddy.glb`).
   - Физически корректное освещение (PBR), тени, вращение и переключение моделей в реальном времени.
   - Поддержка дополненной реальности (**WebXR / SceneViewer / QuickLook**) для мгновенной примерки через камеру телефона.

2. **🌌 Живой физический фон (Canvas Liquid-Goo Simulator):**
   - 60 FPS симуляция жидких капель (метаболлов) с отталкиванием, реакцией на гравитацию курсора и гироскоп смартфона.
   - Поддержка Retina/Hi-DPI экранов без просадок производительности.

3. **🔊 Кибер-звуковой движок (Web Audio API):**
   - Нулевая зависимость от внешних mp3-файлов — звук синтезируется на лету через аудио-осцилляторы при наведении и переключении моделей (с кнопкой включения/выключения звука в шапке).

4. **📐 Эргономичный сплит-интерфейс 50/50:**
   - **Слева:** Профиль, статус доступности для заказов, интерактивная 3D-сцена и быстрые контакты (Telegram, GitHub, Instagram).
   - **Справа:** 4 ключевых направления (3D моделирование, ESP32 микроэлектроника, автономные ИИ-агенты, лазерный и проекционный маппинг).

## 🚀 Быстрый запуск

### 1. Запуск локального сервера (Windows)
Двойной клик по:
```cmd
start.bat
```
Либо в PowerShell:
```powershell
.\start.ps1
```

Сервер автоматически проверяет и освобождает порты (`8088`, `8080`, `8000`), настраивает MIME-типы для 3D моделей и открывает визитку в браузере.

### 2. Деплой на удаленный Linux сервер (192.168.31.195)
```cmd
..\Golos control\venv\Scripts\python.exe deploy_to_server.py
```

### 3. Публикация в GitHub Pages
```cmd
git add .
git commit -m "🚀 Boost: High-End 50/50 Split, Live 3D Model Stage, Web Audio Synth"
git push origin main
```
Сайт автоматически обновляется на: **https://maxsav4.github.io/saite/**
